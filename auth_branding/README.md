# Auth Branding - Custom Odoo Login & Signup Pages

Customize your Odoo authentication experience with a modern, responsive, and fully brandable interface. No more boring default login pages.

## Key Features

- **Multiple Templates**: Choose between Centered Card, Split Screen, and Full Bleed layouts.
- **Background Customization**:
  - Solid colors
  - Linear gradients
  - Dynamic animated gradients
  - Custom background images with overlay opacity control
- **Glassmorphism Effects**: Apply a modern frosted glass effect to your login cards with adjustable blur and opacity.
- **Comprehensive Branding**:
  - Custom Company Logo and Favicon
  - Taglines and Custom Footer Text
  - Primary & Secondary Color customization
  - Text and Button color control
  - Font selection (Inter, Roboto, Open Sans, Lato, Poppins, Georgia, etc.)
  - Adjustable Border Radius for inputs and buttons
- **Live Preview**: See your changes in real-time within the Odoo backend before applying them.
- **Easy Configuration**: Managed directly through Odoo Settings.

## Installation

1. Copy the `auth_branding` folder to your Odoo custom addons directory.
2. Restart your Odoo server.
3. Enable developer mode in Odoo.
4. Go to **Apps** and click **Update Apps List**.
5. Search for `Auth Branding` and click **Install**.

## Usage

1. Navigate to **Settings** > **General Settings**.
2. Find the **Auth Branding** section.
3. Click on the **Configure Auth Branding** button to access the settings and live preview.
4. Customize the colors, backgrounds, and layout to match your brand.
5. Save the configuration to apply changes to your Login, Signup, and Reset Password pages.

## Compatibility

- **Odoo Version**: 19.0
- **Editions**: Community and Enterprise
- **Dependencies**: `web`, `auth_signup`, `base_setup`
