Frequently Asked Questions

Designed for Confident Deployment

Will draft changes affect live users?

No. Public authentication pages read from the active published version only.

Can each company have different branding?

Yes. Configurations, custom presets, schedules, and versions are company-aware.

Can later edits change a scheduled release?

No. A schedule captures an immutable copy of settings and image assets.

Does it support social login?

Yes. Installed Odoo authentication providers receive the selected button presentation.

Can designs move between databases?

Yes. Export a JSON brand package, import it as a draft, review it, and publish separately.

Is custom CSS available?

Yes. Local overrides are supported while unsafe and external constructs are rejected.
